# אפיון מערכת לניהול שיבוץ צוות בבית ספר

> גרסה מעודכנת נכון ל-04/08/2026, משקפת את המערכת כפי שהיא בנויה ופועלת בפועל (לא רק תכנון). מחליפה את "אפיון_מערכת_שיבוץ_צוות (2).md".

## 1. מטרת המערכת

מערכת רב-בית-ספרית (multi-tenant) לניהול שיבוצי צוות (מורות, סייעות, מ"מ) בבית ספר, הכוללת:
- שיבוץ בסיסי קבוע לכל השנה, לכל כיתה
- שיבוץ יומיומי של ממלאות מקום (מ"מ) בחורים הריקים ובהיעדרויות
- מערכת חלופית (טיוטה) לעריכת שיבוץ בלי להשפיע על הפעיל
- קיטנות — מתכונת נפרדת-אך-דומה, עם טווחי תאריכים גמישים
- "מערכות עזר" גנריות (למשל פתיחות) — לא תפקיד קבוע אחד, אלא כל מספר של מערכות תפקידים שבועיות מקבילות
- חופשות עם תזכורות אוטומטיות
- דוחות, היסטוריית שינויים (Audit Log) וייצוא
- ניהול משתמשים והרשאות בשני צירים: הרשאת עריכה מול צפייה, ותפקיד ניהולי (מנהל/ת בית ספר, מנהל/ת מערכת)
- תמיכה בכמה בתי ספר תחת אותה מערכת, כל אחד עם הנתונים שלו בלבד

המערכת בנויה סביב שכבות שימוש:

| # | שלב | מתי |
|---|---|---|
| 1 | הגדרות בסיסיות | תחילת שנה/הקמה — כיתות, תפקידים, קטגוריות עובדות, חגים, פרמטרים |
| 2 | עבודה שוטפת/יומיומית | כל יום — לוח בקרה, ניהול חוסרים, שיבוץ מ"מ |
| 3 | הוצאת עובדת לחופשה | לפי הצורך |
| 4 | ניהול קיטנות | לקראת כל קיטנה |
| 5 | דוחות, היסטוריה וייצוא | לפי דרישה |
| 6 | ניהול מערכת (משתמשים, בתי ספר, פניות) | לפי הצורך, למנהלות/למנהלי מערכת |

## 2. מונחים והגדרות

| מונח | הסבר |
|---|---|
| **בית ספר (School)** | יחידת שוכרת (tenant) עצמאית. לכל בית ספר נתונים נפרדים לחלוטין; משתמש שייך לבית ספר אחד קבוע |
| **כיתה** | יחידת שיבוץ. מוגדרת מחדש כל שנה (ראו 3.2), אינה מקושרת לכיתות משנים קודמות |
| **חלק יום** | בוקר / צהריים. התוויות ושעות התצוגה ניתנות לעריכה לכל בית ספר (ראו 3.9) |
| **חור (Slot)** | תקן תפקיד בכיתה, ביום בשבוע ובחלק יום מסוים |
| **חור קבוע** | חור המשובץ באופן קבוע לעובדת ספציפית |
| **חור ריק (משתנה)** | חור ללא שיבוץ קבוע, המאויש מדי יום ע"י מ"מ שונה |
| **היעדרות חד-פעמית** | עובדת קבועה שלא מגיעה ביום מסוים (או בחלק יום ספציפי); החור נפתח לאותו יום/חלק-יום בלבד |
| **עובדת קבועה / מ"מ** | סטטוס עובדת: בעלת שיבוץ קבוע, או מאיישת חורים ריקים לפי הצורך |
| **קיטנה** | תקופה מוגדרת (שם + כמה "טווחי קיטנה") בה פועלת מתכונת שיבוץ נפרדת |
| **טווח קיטנה (Camp period)** | תת-טווח תאריכים בתוך קיטנה, עם הגדרה עצמאית אם בוקר/צהריים פעילים בו — קיטנה יכולה להכיל כמה טווחים כאלה (למשל שבוע יום-מלא ואז שבוע-בוקר-בלבד) |
| **מערכת עזר (Auxiliary system)** | מערכת תפקידים שבועית עצמאית, נפרדת מהשיבוץ הרגיל (למשל "פתיחות", אך אפשר כל מספר של מערכות כאלה). לכל מערכת: תפקידים, שיבוץ שבועי חוזר, ומקור צוות מועמד |
| **חור ארוך** | אותו תפקיד ריק גם בבוקר וגם בצהריים באותו יום; לא ממוזג — כל חלק מוצג ומשובץ בנפרד |
| **קריטיות (Criticality)** | 3 רמות לכל חור: קריטי / רגיל / לא נדרש איוש. ברירת המחדל נקבעת בתבנית, וניתנת לדריסה חד-פעמית לתאריך ספציפי |
| **הרשאת עריכה (full/view_only)** | ציר הרשאה נפרד מתפקיד ניהולי: קובע האם המשתמשת יכולה לערוך תוכן בית-הספר שלה |
| **תפקיד ניהולי** | מנהל/ת מערכת (`is_system_admin`) / מנהל/ת בית ספר (`is_school_admin`) / משתמשת רגילה — ראו סעיף 7 |

**מבנה כיתה:** מספר התפקידים והכמות בכל חלק יום נקבעים לפי "ברירות מחדל לתפקיד" (role type defaults, ראו 3.4), ולא קבוע (למשל: לא בהכרח מורה + 2 סייעות — ניתן להגדיר כל תמהיל).

## 3. ישויות מידע (Data Model)

תיאור מלא ומדויק של כל ישות וכל שדה מופיע במסמך הנפרד **"אפיון מסד נתונים.md"**. הסעיפים הבאים מתארים את הישויות ברמה פונקציונלית בלבד.

### 3.1 עובדת (Employee)
שם מלא, טלפון, מייל, סוג עובדת (טבלת סוגים חופשית לכל בית ספר — למשל מורה/סייעת, ראו 3.3), קטגוריה (תגית צבעונית חופשית, ראו 3.4), סטטוס (קבועה/מ"מ), מועדפת (למ"מ — מוצגת ראשונה ברשימת בחירה), פעילה (כן/לא — לא-פעילה נעלמת מרשימות בחירה, ההיסטוריה נשמרת), הערות. שם כפול (זהה לעובדת קיימת) חוסם שמירה. ניתנת לייבוא בקובץ CSV (ראו 5.9).

### 3.2 כיתה (Class)
שם בלבד. מוגדרות מחדש כל שנה — אין קישור/היסטוריה חוצת שנים. מסך הכיתות מציג לכל כיתה גם עמודות מחושבות: מספר חורים ריקים פתוחים, וסטטוס השיבוץ הבסיסי (הושלם/חלקי/לא הוגדר) עם קיצור-דרך למסך שיבוץ בסיסי.

### 3.3 סוג עובדת (Employee Type)
קטלוג חופשי לכל בית ספר (למשל מורה/סייעת/בת שירות), ניתן להוספה/עריכה/השבתה, עם סדר תצוגה.

### 3.4 תפקיד וברירות מחדל (Role Type / Role Type Defaults)
"תפקיד" (role type) הוא קטלוג נפרד מ"סוג עובדת" — משמש לבניית חורים בכיתה. לכל תפקיד נקבעת כמות ברירת-מחדל וקריטיות ברירת-מחדל לכל חלק-יום; אלה נצרכים אוטומטית בעת יצירת כיתה חדשה (ובבנייה מחדש של חורי ברירת מחדל לתבנית ריקה).

### 3.5 קטגוריית עובדות (Employee Category)
תגית חופשית עם צבע לתצוגה (למשל "צוות קבוע"/"מ"מ חיצוני"), נערכת במסך ניהול, ניתנת להשבתה.

### 3.6 חור (Slot / Template Slot)
כיתה (דרך התבנית), יום בשבוע, חלק יום, תפקיד, סוג חור (קבוע/משתנה), קריטיות, עובדת משובצת (אם קבוע), הערה חופשית לתא.

### 3.7 רמת קריטיות של חור
| רמה | משמעות | התנהגות מערכת |
|---|---|---|
| **קריטי** | חובה לאייש | בראש דוח החסרים, מודגש |
| **רגיל** | רצוי לאייש | בעדיפות רגילה |
| **לא נדרש איוש** | לא חובה למלא | לא נספר, לא מייצר התראה |

ניתן לשנות בתבנית בכל עת, וגם **לדרוס חד-פעמית לתאריך ספציפי** מהדאשבורד (לא משנה את ברירת המחדל בתבנית).

### 3.8 שיבוץ בסיסי (Schedule Template + Template Slots)
טבלה שבועית קבועה לכל כיתה, ניתנת לעריכה בכל עת (כולל שינוי עובדות בחורים הקבועים). המסך מזהה ומאפשר לתקן אוטומטית חורים כפולים (אותו יום+חלק-יום+תפקיד פעמיים) שעלולים לגרום לאי-סנכרון מול הדאשבורד, ומאפשר לבנות מחדש חורי ברירת מחדל אם לתבנית אין חורים כלל.

### 3.9 שיבוץ יומי (Daily Assignments / Absences / Urgency Overrides)

**א. היעדרות חד-פעמית:** כפתור "לא הגיעה היום" פותח חור זמני ליום זה בלבד (ניתן גם ברמת חלק-יום ספציפי), מבלי לגעת בשיבוץ הקבוע.

**ב. שיבוץ מ"מ לחור ריק:** רשימת הבחירה מציגה את כל העובדות, כולל משובצות במקום אחר (מסומנות). בחירה בעובדת שכבר משובצת באותו תאריך+חלק-יום מציגה אישור "העברה" — מוחקת מהחור הישן ומשבצת בחדש.

**ג. דריסת קריטיות חד-פעמית:** ניתן לשנות את רמת הקריטיות של חור ספציפי לתאריך נתון בלבד (לא לתבנית), מהדאשבורד.

### 3.10 חופשה/היעדרות ממושכת (Leave)
עובדת, תאריך התחלה/סיום, מספר ימים לתזכורת, הערות. אפשר לשייך מ"מ מראש לימים/חלקי-יום ספציפיים בטווח (עד מ"מ שונה לבוקר ולצהריים באותו יום). ביטול חופשה עם מ"מ ששובצו כבר מזהיר שהביטול ימחק את השיבוצים. תזכורת חזרה נשלחת אוטומטית X ימים לפני, וכל משתמשת יכולה לסמן "הבנתי" עבור עצמה בנפרד (הדחייה אינה גלובלית).

### 3.11 טיוטת שיבוץ לכיתה — "מערכת חלופית" (Draft)
עותק מלא של תבנית השיבוץ לכיתה, נערך בחופשיות בלי להשפיע על הפעיל. "החלת טיוטה" בשני מצבים: **החלפה מלאה** (מיידית, קבועה, בלתי הפיכה) או **טווח תאריכים מוגדר** (valid_from/valid_to — פעילה רק בטווח שהוגדר; החלה חדשה מחליפה טווח קודם אם קיים). ניתן לזנוח טיוטה בלי השפעה.

### 3.12 קיטנות (Camps)
קיטנה היא רשומה קבועה — **לעולם לא נמחקת, רק נערכת**; מוצג לה סטטוס מחושב (עתידית/פעילה/הסתיימה) לפי תאריך היום מול טווח הקיטנה. לקיטנה יכולים להיות **כמה "טווחי קיטנה"** (camp periods) בתוך טווח הכללי, כל אחד עם הגדרה עצמאית אם בוקר/צהריים פעילים בו (למשל שבוע יום-מלא ואז שבוע-בוקר-בלבד). ימים/חלקי-יום שאינם בתוך אף טווח מוצגים כתאים מושבתים. מסך הקיטנה משלב רשת שבועית אחת (כמו דאשבורד) שכוללת גם את השיבוץ הבסיסי של הקיטנה וגם שיבוץ מ"מ יומי — אין מסך "שיבוץ בסיסי" נפרד לקיטנה; העריכה ישירה מהתא, בדיוק כמו שיבוץ מ"מ יומי. כולל גם קטע מתקפל למערכת עזר (המערכת הפעילה הראשונה) בהיקף קיטנה+שבוע.

### 3.13 מערכות עזר (Auxiliary Systems) — כללי, לא רק "פתיחות"
כל בית ספר יכול להגדיר **כל מספר** של מערכות עזר עצמאיות (למשל כמה סבבי תפקידים שונים), ולא רק תפקיד פתיחה יחיד:
- שם, מקור צוות מועמד (מי מוצגת ברשימת הבחירה: משובצות בוקר / משובצות צהריים / כל עובדת פעילה)
- האם להציג את חוסרי המערכת בדאשבורד/שיבוץ חוסרים ("show_in_missing")
- תפקידים משלה (שורות) × ימי שבוע (עמודות), שיבוץ שבועי חוזר של עובדת אחת לכל תא (לא מחולק בוקר/צהריים)
- השבתת מערכת שומרת את הנתונים אך מסתירה אותה בכל מקום
- עריכה מותרת רק להרשאת עריכה מלאה (full)
- לכל קיטנה יש היקף מקביל של מערכת עזר (לפי שבוע קיטנה, ראו 3.12)

### 3.14 חגים ומועדים (School Holidays)
תאריך + תווית חופשית + סוג: **יום חופש מלא** (מבטל בוקר וצהריים כאחד בדאשבורד ומוסתר משיבוץ חוסרים) או **יום קצר** (מבטל רק חלק-יום ספציפי — בוקר או צהריים, לפי בחירה). ניתן לייבוא בקובץ CSV.

### 3.15 פרמטרים ברמת בית-ספר (School Settings)
תצוגת ברירת מחדל בדאשבורד (יום/שבוע), מצב הצגת תאריכים (עברי/לועזי/שניהם), תוויות ושעות תצוגה לבוקר/צהריים (תצוגתי בלבד, לא משפיע על לוגיקת שיבוץ — כן משפיע על חישוב שעות עובדת).

### 3.16 פרמטרים ברמת מערכת (System Settings)
שורה גלובלית אחת: זמן ניתוק אוטומטי (בדקות) בעקבות חוסר פעילות — עריכה ל-מנהל/ת מערכת בלבד.

### 3.17 בית ספר (School) ומשתמשים (Profile)
ראו סעיפים 7-8 להרחבה על הרשאות ומשתמשים.

### 3.18 פניות "צור קשר" (Contact Requests)
שם מלא, טלפון/מייל, פרטים חופשיים, בית ספר ומשתמשת ששלחה. סטטוס: חדשה → נצפתה (מסומן אוטומטית עם פתיחת חלון הפרטים) → טופלה (סימון ידני, ניתן לביטול). נראה רק למנהל/ת מערכת ראשי/ת.

## 4. כללי עסק (אילוצים)

1. **איסור כפילות באותו חלק יום:** עובדת לא יכולה להיות משובצת לשני חורים שונים באותו יום ובאותו חלק יום — הבחירה בעובדת כפולה מציעה "העברה", לא חוסמת מוחלטת.
2. **מותר "פיצול" בין חלקי היום:** אותה עובדת יכולה להיות משובצת בבוקר בכיתה אחת ובצהריים בכיתה אחרת.
3. חור קבוע יכול להיות מוחלף חד-פעמית ע"י מ"מ, מבלי לבטל את השיבוץ הקבוע לטווח הארוך.
4. **עריכה גורפת:** כל תוכן טקסטואלי ניתן לעריכה בכל עת, בכפוף להרשאת עריכה מלאה (full).
5. **כיתות אינן מקושרות בין שנים** — כל שנה מתחילה מרשימת כיתות ריקה, אך "איפוס שנה" (5.11) אינו מוחק כיתות/עובדות באופן אוטומטי — רק מארכב שיבוצים/חופשות/קיטנות/חגים/היסטוריה.
6. **בידוד בין בתי ספר:** כל הנתונים מסוננים לפי `school_id`; משתמשת רגילה אינה יכולה לראות או לערוך נתונים של בית ספר אחר.
7. **מחיקה רכה (Soft delete):** רוב הישויות התומכות בהיסטוריה חוצת-זמן (שיבוצים, חופשות, קיטנות, חגים, מערכות עזר וכו') אינן נמחקות פיזית אלא מסומנות (`archived_at`/`active=false`) — ראו מסמך מסד הנתונים.

## 5. פונקציונליות נדרשת (לפי מסך)

### 5.1 לוח בקרה — Dashboard (`/`)
מסך הבית. בחירת טווח (יום/שבוע נוכחי, עם ניווט חצים + כפתור "היום" + קפיצה ישירה לתאריך) והיקף (כל הכיתות/כיתה ספציפית — אך החישוב תמיד בודק כפילויות מול כל הכיתות, גם כשמוצגת כיתה אחת). כל הכיתות שבהיקף מוצגות ברשת רספונסיבית, תאריכים בלוח העברי (ניתן לשינוי ל-לועזי/שניהם, 3.15). כפתור "לא הגיעה היום" בתוך כל תא של עובדת קבועה. שיבוץ מ"מ נעשה ישירות מתוך תא החור הריק. חגים (מלאים/קצרים) מבטלים תאים בהתאם (3.14). בראש המסך, קטע מתקפל של חוסרי מערכות עזר (3.13) המחושב לפי נוכחות בפועל (כולל היעדרויות/חופשות) ולפי דריסות קריטיות יומיות (3.9-ג). **זהו גם דוח החסרים** — לא מסך נפרד: אין הבדל בין "צפייה" ל"שיבוץ בפועל", הצביעה (כחול=קבועה, ירוק=מ"מ, אדום/כתום=ריק לפי קריטיות) זהה בשני ההקשרים.

### 5.2 שיבוץ בסיסי (`/base`)
עורך תבנית שבועית פעילה לכיתה נבחרת. מזהה חורים כפולים ומאפשר תיקון אוטומטי; יכול לבנות מחדש חורי ברירת מחדל אם לתבנית אין חורים.

### 5.3 שיבוץ חוסרים / מ"מ — Substitute Assignment (`/missing`)
מסך העבודה השוטף למילוי חוסרים: מיתוג יום/שבוע, מיתוג לפי-כיתה/לפי-חלק-יום, ניווט תאריכים (מדלג על שבתות בתצוגת יום). שני חלקים: חוסרי חורי כיתה (ממוינים עם פתוחים+קריטיים בראש) וחוסרי מערכות עזר (`show_in_missing`), עם שיבוץ מ"מ ישיר.

### 5.4 רשימת מ"מ (`/substitutes`)
כרגע מסך שלד ("בבנייה") — לא מומש עדיין.

### 5.5 דוח עובדת (`/employee`)
בחירת עובדת + טווח תאריכים → כל תאריך+כיתה שבו עבדה בפועל (קבועה, מ"מ, או מ"מ-חופשה — לא היעדרויות/חופשות עצמן), מיזוג בוקר+צהריים לשורת "ארוך" אחת כשרלוונטי, אפשרות הצגת/הסתרת עמודת כיתה, כותרת חוזרת בכל עמוד הדפסה.

### 5.6 קיטנות (`/camps`, `/camps/:campId`)
רשימת כל הקיטנות (לא נמחקות, רק נערכות), עם סטטוס מחושב. מסך פרטי קיטנה: רשת שבועית משולבת (שיבוץ בסיסי + מ"מ יומי) עם תמיכה בכמה טווחי-קיטנה שונים, וקטע מערכת עזר מתקפל לפי שבוע.

### 5.7 מערכת חלופית / טיוטה (`/draft`)
יצירת טיוטה לכיתה, עריכה חופשית, החלה במצב מלא או מוגבל-תאריכים, זניחה בלי השפעה (3.11).

### 5.8 מערכות עזר (`/opening`)
ניהול כל מספר של מערכות עזר עצמאיות: הגדרה, תפקידים, שיבוץ שבועי חוזר, השבתה (3.13).

### 5.9 עובדות (`/staff`)
רשימה עם עמודות: קטגוריה (צבע), סטטוס, מועדפת (למ"מ), **שעות שבועיות מחושבות** (עם סינון טווח מספרי), הוספה/עריכה/השבתה, חסימת שם כפול, ניהול חופשה (הוספה/עריכה/ביטול — ביטול עם מ"מ ששובצו מזהיר על מחיקתם), **ייבוא CSV**: הורדת תבנית → מילוי באקסל → העלאה → תצוגה מקדימה מאומתת שורה-שורה (שגיאות מודגשות ומפורטות, שורות שגויות לא מיובאות) → ייבוא שורות תקינות. שם מלא הוא השדה החובה היחיד; שם כפול (מול קיים או בתוך הקובץ) חוסם שורה. סינון עמודות + עימוד מלאים.

### 5.10 כיתות (`/classes`)
רשימה עם עמודות מחושבות: חורים ריקים פתוחים, סטטוס שיבוץ בסיסי (הושלם/חלקי/לא הוגדר) + קיצור-דרך למסך שיבוץ בסיסי. השבתה רכה בלבד.

### 5.11 ניהול (`/management`) — פרמטרים ברמת בית-ספר, עריכה להרשאת full בלבד
- ברירת מחדל לדאשבורד (יום/שבוע), מצב הצגת תאריכים (3.15)
- תוויות ושעות תצוגה לבוקר/צהריים
- תפקידים וכמויות ברירת מחדל + קריטיות (3.4)
- קטגוריות עובדות (3.5)
- חגים ומועדים, כולל ייבוא CSV (3.14)
- **"פתיחת שנה חדשה" (אזור מסוכן):** מארכבת (רכה, `archived_at`, לא מוחקת) את תבניות השיבוץ, החופשות, הקיטנות, החגים, השיבוצים/היעדרויות היומיים וההיסטוריה של השנה הנוכחית, דרך פונקציית DB `start_new_year`. עובדות, כיתות והגדרות בית-הספר אינן נגועות. דורשת הקלדת ביטוי אישור מדויק ("איפוס שנה"), אינה הפיכה מהממשק.

### 5.12 היסטוריה (`/history`)
צפייה בלוג ביקורת (Audit Log): טווח תאריכים (ברירת מחדל 30 יום אחרונים, כפתור קיצור), סינון עמודות (תאריך/כיתה/פעולה/פירוט/משתמשת) + עימוד (25 בעמוד). מציג שני סוגי אירועים: שיבוצי מ"מ (יצירה/עדכון/מחיקה, ערך ישן→חדש) והיעדרויות ("לא הגיעה היום" — סימון/ביטול). מציג את שם המשתמשת שביצעה את הפעולה.

### 5.13 ניהול מערכת (`/system-admin`) — מנהל/ת מערכת בלבד
שלוש לשוניות:
- **בתי ספר:** יצירת בית ספר חדש (שם), השבתה/הפעלה רכה, קביעת מספר מקסימלי של משתמשות עם הרשאת עריכה מלאה לבית ספר (צפייה-בלבד ללא הגבלה)
- **משתמשים:** ניהול משתמשים חוצה-בתי-ספר
- **הגדרות:** זמן ניתוק אוטומטי גלובלי (3.16)

### 5.14 ניהול משתמשים (`/manage-users`) — מנהל/ת בית ספר (או מנהל/ת מערכת)
זהה בעיקרון ל-5.13/משתמשים, אך מוגבל למשתמשות בבית הספר של המנהל/ת בלבד; אינו מאפשר הענקת תפקידי ניהול (is_system_admin/is_school_admin) ואינו נוגע במנהלים אחרים.

### 5.15 פניות "צור קשר" (`/contact-requests`) — מנהל/ת מערכת בלבד
תיבת פניות שהוגשו מטופס "צור קשר" (בפוטר): לשוניות "הכול/לא נקראו", סינון עמודות, חלון פרטים (מסמן "נצפתה" אוטומטית בפתיחה), כפתור "סמן כטופלה"/ביטול.

### 5.16 ייצוא נתונים
כפתור ייצוא בכל מסך רלוונטי, שתי אפשרויות:
- **PDF:** פותח את דיאלוג ההדפסה של הדפדפן ("שמור כ-PDF")
- **Excel:** למעשה קובץ CSV (עם BOM לתמיכה בעברית באקסל), הנבנה מכל הטבלאות הגלויות במסך באותו רגע (מכבד סינון/עימוד גלוי, מדלג על עמודות פעולה עם כפתורים)

### 5.17 ניתוק אוטומטי (Idle Logout)
ניתוק אוטומטי לאחר N דקות ללא פעילות (עכבר/מקלדת/גלילה/מגע), הזמן נלקח מהגדרת מערכת גלובלית (3.16). זמן הפעילות האחרון נשמר ב-localStorage כך שכל הכרטיסיות הפתוחות חולקות שעון אחד (פעילות בכרטיסייה אחת מאפסת את כולן), נבדק כל 10 שניות.

## 6. תרחישי שימוש עיקריים

1. **מנהלת מזינה שיבוץ בסיסי** בתחילת השנה, כולל הגדרת כיתות חדשות מאפס.
2. **מזכירה משבצת מ"מ** לחורים הריקים של אותו יום, כולל היעדרויות חד-פעמיות.
3. **עובדת מודיעה שלא מגיעה היום** → "לא הגיעה היום" → שיבוץ מ"מ לחור החד-פעמי.
4. **בדיקה יומית/שבועית** בדאשבורד — גם דוח החסרים.
5. **הקמת קיטנה** עם כמה טווחי-קיטנה שונים (יום-מלא/בוקר-בלבד) → עריכה → שיבוץ מ"מ יומי → מערכת עזר לפי שבוע.
6. **הפקת דוח לעובדת**.
7. **הוצאת עובדת לחופשה**, כולל שיוך מ"מ מראש לחלקי-יום ספציפיים.
8. **בניית טיוטה לכיתה** והחלתה — מלאה או לטווח תאריכים מוגדר.
9. **ניהול מערכות עזר** — כל מספר של מערכות מקבילות, לא רק פתיחה אחת.
10. **צפייה בהיסטוריה** לפי טווח תאריכים ופעולה.
11. **ייבוא עובדות/חגים בקובץ CSV** עם תצוגה מקדימה ואימות.
12. **מנהל/ת מערכת מוסיפה בית ספר חדש** וקובעת מכסת משתמשות עם הרשאת עריכה.
13. **מנהל/ת בית ספר מזמינה משתמשת** לבית הספר שלה בלבד.
14. **מנהל/ת מערכת מטפלת בפנייה** שהתקבלה מטופס "צור קשר".
15. **פתיחת שנה חדשה** — מארכבת שיבוצים/חופשות/קיטנות/חגים של השנה שהסתיימה.

## 7. משתמשים והרשאות

הרשאות נבנות משני צירים בלתי-תלויים:

**א. ציר ניהולי (role):**
| תפקיד | היקף |
|---|---|
| **מנהל/ת מערכת (`is_system_admin`)** | גישה לכל בתי הספר, למסכי ניהול מערכת, ולפניות "צור קשר" |
| **מנהל/ת בית ספר (`is_school_admin`)** | גישה מצומצמת ללשונית ניהול משתמשים, מוגבלת לבית הספר שלו/ה בלבד — אינו יכול/ה להעניק תפקידים ניהוליים ואינו נוגע במנהלים אחרים |
| **משתמשת רגילה** | אינה רואה מסכי ניהול מערכת/פניות/ניהול משתמשים |

**ב. ציר הרשאת עריכה (permission_level), בתוך היקף בית הספר:**
| רמה | היקף |
|---|---|
| **מלאה (full)** | עריכה מלאה בכל מסכי בית הספר |
| **צפייה בלבד (view_only)** | צפייה בלבד, ללא עריכה; אינה מוגבלת בכמות |

מספר המשתמשות עם הרשאת עריכה מלאה מוגבל לכל בית ספר (נקבע ע"י מנהל/ת מערכת, 5.13).

## 8. תיעוד היסטורי

- כל שינוי בשיבוצי מ"מ והיעדרויות נשמר בלוג ביקורת (Audit Log) עם ערך ישן/חדש, תאריך ומבצעת השינוי — נצפה במסך היסטוריה (5.12).
- קיטנות שהסתיימו נשמרות במלואן וניתנות לצפייה חוזרת — לעולם לא נמחקות (3.12).
- כיתות אינן נשמרות בהיסטוריה חוצת-שנים.
- "פתיחת שנה חדשה" (5.11) מארכבת (לא מוחקת) שיבוצים/חופשות/קיטנות/חגים/היסטוריה של השנה שהסתיימה.
- משמש כבסיס לדוח עובדת ולצרכי שכר/בקרה.

## 9. סיכום החלטות עדכני

| נושא | מצב נוכחי |
|---|---|
| ריבוי בתי ספר | נתמך במלואו — כל בית ספר מבודד, מנוהל דרך מסך ניהול מערכת |
| היקף כיתות | דינמי, לא קבוע (14 בוטל כהחלטה נעולה) |
| תפקידים בכיתה | דינמיים, לפי "תפקידים וברירות מחדל" (3.4) — לא בהכרח מורה+2 סייעות |
| קטגוריות עובדות | תגית חופשית עם צבע, ברמת בית ספר |
| משתמשים והרשאות | שני צירים: תפקיד ניהולי (מערכת/בית-ספר/רגיל) × הרשאת עריכה (מלאה/צפייה) |
| מכסת עורכות | מוגבלת לכל בית ספר בנפרד ע"י מנהל/ת מערכת |
| רשימת מ"מ | ניהול מלא + ייבוא CSV (לא רק חד-פעמי בהקמה) |
| ייבוא נתונים | CSV לעובדות ולחגים, עם תצוגה מקדימה ואימות שורה-שורה |
| תיעוד היסטורי | Audit Log אמיתי, לפי תאריך/כיתה/פעולה/משתמשת, עם עימוד |
| ייצוא | PDF (הדפסת דפדפן) + Excel (CSV עם BOM), ממומש בפועל בכל מסך רלוונטי |
| רמות קריטיות לחור | 3 רמות, ברירת מחדל בתבנית + דריסה חד-פעמית לתאריך |
| חופשות | טווח חופשי + תזכורת X ימים לפני (דחייה פר-משתמשת) + שיוך מ"מ מראש לימים/חלקי-יום |
| עריכת שיבוץ קבוע | בכל עת |
| טיוטת שיבוץ (מערכת חלופית) | החלה מלאה או לטווח תאריכים מוגדר (valid_from/valid_to) |
| מערכת פתיחות | הוכללה ל"מערכות עזר" — כל מספר של מערכות מקבילות, כל אחת עם מקור צוות מועמד ו-show_in_missing משלה |
| קיטנות | ישויות קבועות שלא נמחקות; יכולות להכיל כמה "טווחי קיטנה" עם הגדרת בוקר/צהריים עצמאית לכל טווח |
| חגים | תומכים גם ביום חופש מלא וגם ביום קצר (בוקר בלבד/צהריים בלבד), עם ייבוא CSV |
| כיתות | מוגדרות מחדש כל שנה, ללא קישור/היסטוריה בין שנים; "פתיחת שנה" מארכבת שיבוצים בלבד |
| היעדרות חד-פעמית | כפתור "לא הגיעה היום", גם ברמת חלק-יום ספציפי |
| דאשבורד ודוח חסרים | מסך אחד ומאוחד, כולל חוסרי מערכות עזר מחושבים לפי נוכחות בפועל ודריסות קריטיות יומיות |
| רשימת מ"מ (מסך `/substitutes`) | **טרם מומש** — מסך שלד בלבד |
| ניתוק אוטומטי | זמן גלובלי, ניתן לעריכה ע"י מנהל/ת מערכת, מסונכרן בין כרטיסיות |
| פתיחת שנה חדשה | פונקציונליות ממומשת, מארכבת נתוני שנה, דורשת הקלדת ביטוי אישור |
